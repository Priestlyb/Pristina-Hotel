## Overview

**Pristina Hotel** is a modern hotel web platform built to provide guests with a polished and intuitive digital experience for discovering hotel information, exploring rooms and services, and interacting with booking-related workflows.

The project focuses on building a production-oriented frontend with a clean component architecture, responsive layouts, intuitive navigation, and engaging interactions across different screen sizes.

The application is part of a broader hotel technology ecosystem, with the frontend designed to integrate with backend services responsible for hotel operations, data management, authentication, and booking functionality.

## Architecture

The application follows a component-based React architecture designed to keep the codebase modular and maintainable.

```text
Pristina Hotel
│
├── Presentation Layer
│   ├── Pages
│   ├── Components
│   └── Responsive UI
│
├── Application Layer
│   ├── Routing
│   ├── User Flows
│   └── UI State
│
└── Infrastructure
    ├── API Integration
    └── Vercel Deployment
```

The architecture is designed to allow additional hotel functionality to be introduced without requiring significant restructuring of the existing frontend.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 18+
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Priestlyb/Pristina-Hotel.git
```

Navigate into the project directory:

```bash
cd Pristina-Hotel
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

---

## Production Build

Create an optimized production build with:

```bash
npm run build
```

The optimized application will be generated inside the `build/` directory.
